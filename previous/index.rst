Previous versions
=================

The documentation for earlier releases is kept here as it was published for
each release, so you can check what a version you are still running did. The
pages are not updated, and they describe that version only. For anything
current, use the :doc:`main documentation <../index>`.

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Version
     - Documentation
   * - 0.96.0
     - `User and scripting documentation <0.96.0/index.html>`__, including the
       `API reference <0.96.0/api.html>`__.
   * - 0.95.10
     - `Scripting API reference <0.95.10/lib.scripting-module.html>`__
       (`with frames <0.95.10/frames.html>`__), generated with epydoc from
       the 0.95.10 sources.
